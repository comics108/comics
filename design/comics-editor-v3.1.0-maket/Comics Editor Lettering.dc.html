Addition · Lettering · HolySpots DS v3.0

Lettering & layer kinds

Two additions to the v3.0 workspace: kind badges in the layer list (violet = balloon, amber = caption, gray = art — always color + label, never color alone) and a focused Lettering mode — a DaVinci-style page switch with a balloon rail, per-language text, and AI generation with a visible on-device / cloud routing indicator. Shown for macOS, iPad and iPhone.

Layer-kind badges — Scene panel
A small kind chip before the thumbnail, everywhere the layer list appears. Legacy files with no kind field render exactly as today.
