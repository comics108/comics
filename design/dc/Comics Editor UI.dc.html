Comics Editor 2.8 — UI Specification

Faithful reproduction of the WPF desktop editor (Comics.Editor). Every window, side panel, in-place editor and system dialog drawn as-is — no invented functionality. Windows Aero / .NET default theme. The companion web admin is out of scope.
